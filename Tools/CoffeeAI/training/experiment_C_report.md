## 六、新增错误与模板化风险（诚实记录，GPT：不预设成功）

**新增/残留错误（均相对同策略 base）**：
1. **nat_q7 豆油机理编造**：「成熟/发酵/脱水过程形成油脂」——机理错误（真实：烘焙
   使豆内脂质迁移至表面，深烘明显）。base 不精确但方向对。**本轮最严重的单点劣化**。
2. **nat_q4「咖啡中的糖分和脂肪含量较高」**——黑咖啡低糖低脂，表述失实（健康题上
   出现事实性错误，需警惕）。
3. gov_q9「美国心脏协会建议 400mg」——来源归属存疑（该口径通常归于 FDA/EFSA）。
4. nat_q1 编造品牌「Vestmark」+V60 锥形/圆柱自相矛盾。
5. nat_q6/nat_q9 的法压「压力萃取」与「水洗部件」——base 同样存在（小模型通病，非
   训练劣化）。

**模板化风险**：零「万事追问」——20 题中追问类错误为零（同 B）；直接解释题全部
直接回答（N3/N6/N7/N8/N9/N10 无一转追问）。GPT 担心的模板机未出现 ✓。
