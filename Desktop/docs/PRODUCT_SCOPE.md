# 产品范围

BrewPhase Desktop 是 BrewPhase iOS 的**桌面协同版**，不是它的复制品，也不是单纯的
Canvas 编辑器。三个业务模块同级：

| 模块 | 它回答的问题 |
| --- | --- |
| Coffee | 我有什么豆、怎么冲的、好不好喝、什么时候该喝 |
| Records | 我收集了什么，以后还找不找得回来 |
| Canvas | 我把这些东西放到一起，怎么摆、怎么想 |

## 做什么

- **本地优先**：数据在本机 SQLite + media 目录，不需要账号，不依赖网络。
- **与 iOS 同语义**：实体、字段、库存规则、阶段规则、画布坐标都对齐；桌面端不发明
  第二套模型。
- **宽屏优先**：三栏（导航/列表 → 工作区 → 检查器），信息密度高于手机，但不做后台
  管理面板那种统计卡片墙。
- **画布是空间，不是列表**：自由摆放、无限画布、节点保留世界坐标。

## 不做什么（这一版）

- 不做云同步、账号、社交、协作。
- 不做 AI 自动整理/推荐。
- 不把 Records 做成社交信息流。
- 不把 Canvas 做成流程图/白板工具（不强制对齐、不自动排版）。
- 不改 BrewPhase Logo，不引入第二套视觉语言。

## 视觉

Quiet Coffee Atelier：奶油纸色、低饱和、编辑式排版、克制的分隔线。留白比装饰重要，
内容比容器重要。具体色值与字号见 `src/renderer/src/styles/app.css` 的 CSS 变量。

## 与 iOS 的边界

| 能力 | iOS | Desktop |
| --- | --- | --- |
| 数据 | 唯一真源（用户手上） | 同一份数据的另一份，本地库 |
| 同步 | 客户端 | Host（Phase 2） |
| 画布手绘 | 未实现 | 表结构就绪，工具 Phase 4 |
| 视频播放 | 已实现 | Phase 3 |
| 链接抓取 | 已实现 | Phase 3（当前只有用户填的标题/网址） |
