# 2026-11-05

## 首页 UI 重构：Sublime 式堆叠卡片 + 中性底色（已完成）

目标：照 Sublime Internet 的界面语言重做 BrewPhase —— 中性白灰底、少容器、排版建层级，
咖啡色只做小面积品牌点缀。**只改视觉与视图结构，业务逻辑/Schema/引擎一律未动。**

### 底色体系（`Shared/Theme.swift`）
- `paper` 从暖米白 `#FAF7F2` → 中性 `#F7F7F7`；`well` `#F0F0F0`、`hairline` `#E3E3E3`、
  `inkSoft` `#6F6A64`、`inkFaint` `#9E9A94`。咖啡色 token（espresso/roast/latte/cream/moss）
  与阶段色**全部保留原值**，只是不再大面积铺。
- `Card` 改为默认无阴影、只有 hairline；`lifted` 只留给首页那张聚焦卡。
- `PrimaryButton` 改 espresso 实心（全页唯一实心按钮）；`SecondaryButton` 从 cream 改 `well`；
  `FlavorChip`/各处 cream 胶囊全部换 `well`（`PhotoFieldView`/`PhaseRulesView`/`AskView`/`AnswerBody`）。
- 新增 `SectionLabel`（section 小标题的唯一出处，`SectionHeader` 复用它）。
- 新增 `TypeScale.display(30)` / `beanName(26)`、`Metric.stackPeek=13` / `stackDepthScale`、
  `Motion.swipe`。**没有删任何旧 token。**

### 首页（`Features/Home/`）
- `HomeView` 重写：自绘标题「豆仓 / N 包在喝 / +」，隐藏导航栏；中部 `BeanStack`；
  底部「最近一杯」（细线分隔的轻量行 + 记一杯）+「已喝完 N 包」折叠入口。
  旧的 TodayCard、阶段统计 Chip 行、每包一张卡片的列表全部移除。
- `BeanStack.swift`：ZStack + DragGesture 的连续进度模型（`progress = index - pan/width`，
  每张卡按 `depth = i - progress` 求 scale/offset/opacity/zIndex）。只有最前一张可点；
  边缘橡皮筋、快滑用 `predictedEndTranslation`、`sensoryFeedback(.selection)`。
  后退手势时前卡跟随手指（`visual = isFront ? min(depth,0) : depth`），不会先缩进堆里。
- `FocusedBeanCard`：阶段点+名称 … Day、92pt 缩略图、豆名 26pt、烘焙商、单行理由
  （`verdict.details.first ?? closing ?? resting headline`）、PhaseTrack、
  「剩余 Xg」、`开始冲煮`。**故意不含**：还能冲几次、预计喝完、风味标签、评分、历史。
- 排序完全沿用 `InsightFactory.ranked` + `PriorityEngine`；`focusedID` 按 id 而非下标保持焦点，
  记录一杯后重排不会换成另一包豆。
- `BeanRow.swift`（已喝完的紧凑行）取代 `BeanCard.swift`；`PhaseSection.swift`（原 PhaseCard，
  去卡片化）取代 `PhaseCard.swift`。三个旧文件已删除。
