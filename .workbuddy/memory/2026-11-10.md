### 限制与经验

- 仓库 secrets 为空，Windows 包**未做 Authenticode 签名**（SmartScreen 会拦），仅供内测；
  MCP V1 不支持 Windows；未做实机安装 / 启动 / 退出冒烟验证。
- 本机通过代理拉大文件极慢：Actions artifact（134 MB）5 分钟只下到 13 MB；
  `pnpm install` 11 分钟未跑完已终止。**大文件发布优先让 GitHub runner 直接上传 Release**，
  不要本机下载再上传。
- `git push` 首次报 `CONNECT tunnel failed, 502` 是代理瞬时故障，加
  `-c http.version=HTTP/1.1` 重试即成功。
