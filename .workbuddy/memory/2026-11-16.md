**踩到的两个坑（已写进 MEMORY.md）**：

* **notarytool / codesign --timestamp 都被系统代理害死**：HTTP/HTTPS/SOCKS 全指
  `127.0.0.1:7897` 时走 loopback 撞 MITM 证书，报 SSL -1200（`unable to verify the first
  certificate`）。`env -u http_proxy …` 不够，必须 `networksetup -set*proxystate Wi-Fi off`
  临时关掉系统代理，`trap` 保证恢复（本次两次都恢复成功，`scutil --proxy` 复核过）。
* **uploads.github.com 的 IP 不是 140.82.x.x**：那是 `github.com` web 前端，打资产端点返回
  301 到 `github.com/repos/...`。真实记录是 CNAME `alambic-origin.githubusercontent.com` →
  `20.205.243.161`（DoH 可查）。直连该 IP 上传 130MB 只要 ~30 秒（此前以为要 7 分钟）。
  另：zsh 不对字符串变量分词，IP 列表必须写成数组，否则 `--resolve` 拼成两个参数 → HTTP 000。
