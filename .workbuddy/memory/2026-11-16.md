### 补：全量测试的「假失败」定位（同日 13:31）

改完顺序后全量测试连续三次 `** TEST FAILED **`（exit 65），但日志里
`0 failed test cases`、每个 suite 都 passed。真相是两层：

1. **测试宿主重启**：日志出现 3 次 `Restarting after unexpected exit, crash, or test timeout;
   summary will include totals from previous launches`，xcodebuild 因此判失败——
   尽管最后一条汇总行是 `Executed 5xx tests, 0 failures`。累计数（411/528/535）会随重启
   变化，**不能拿它当总数**。
2. 收尾时还有一条 `Failure collecting diagnostics from simulator: Process exited with error
   72: xcrun: error: unable to find utility "simctl"`（`xcode-select -p` 指 CommandLineTools）。

`-collect-test-diagnostics never` 只消掉了第 2 条，第 1 条还在 ⇒ 仍 FAILED。

**有效解法**：不用 `shutdown all`（治不了根），**新建一台干净模拟器**跑一次即
`Executed 801 tests, with 3 tests skipped, 0 failures` + `** TEST SUCCEEDED **`，无重启。
用完 `simctl delete` 删掉。老设备（iPhone 17 Pro / 810C6408）反复 `run.sh` 卸载重装后
状态已脏，重启也救不回来。

判据补充：**先看 `Restarting after unexpected exit` 出现几次**——出现就换干净模拟器重跑，
别去改代码；`Executed N tests` 只有在「无重启」那一次才是真实总数（801）。

  auth_sessions 设计参照。

  不引 Auth.js）；localhost 回调为主/deep link 后续；refresh rotation+token_family
