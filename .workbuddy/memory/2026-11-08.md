### 真机网络环境事实（2026-11-08 排查）

- **`/etc/hosts` 里有 Steam++（Watt Toolkit）的加速段：第 11–59 行，
  48 个域名全部钉到 127.0.0.1**，含 `github.com`(50 行)、`api.github.com`(30 行)、
  `raw.github.com`、`github.io` 等。**关掉 VPN/代理不会清掉它**——这是静态 hosts
  条目，只有 Steam++ 停止加速（或手动删段）才会恢复。
- 证据：绕过 hosts 直查路由 DNS，`api.github.com` → `20.205.243.168`，
  `curl --resolve` 请求 API 返回 **HTTP 200 + 真实仓库 JSON**。即网络与代码都没问题。
- YouTube / X 不在 hosts 段里，它们的 live smoke 失败是**可达性**问题（无代理被墙），
  与 GitHub 不同因。
- 本沙箱 `sudo` 不可用（operation not permitted），改 /etc/hosts 必须用户自己做：
  `cp /etc/hosts /tmp/hosts.bak && sudo sed -i '' '11,59d' /etc/hosts`。
