## 修掉一个编译警告：`BrewDiagnosticEngine.swift:370` 未使用的 `stats`

用户报的警告：`Immutable value 'stats' was never used`。位置是规则 4「参数偏离个人
区间」里的多重 guard：

```swift
guard let value = current.value(of: parameter),
      let range = baseline.range(of: parameter),
      let stats = baseline.stats(of: parameter)   // ← 绑了没用
else { continue }
```

多绑了一个 —— `PersonalBaseline.range(of:)` 的实现就是 `stats(of:)?.range`，
拿到区间就等于拿到了统计。删掉这一行，并在原处留了一句注释说明为什么不缺它。

## 一个值得记住的坑：**增量构建看不见警告**

前几轮我每次都在 grep 警告，结果一直是空的 —— 因为那些构建是增量的，
`BrewDiagnosticEngine.swift` 没被重新编译，编译器自然不会重新报它的警告。
用户在 Xcode 里点了一次构建（重编译了那个文件）才看到。

清点警告的正确姿势：

```bash
rm -rf /tmp/bpw-sym2 /tmp/bpw-obj2        # 必须清，否则等于没查
xcodebuild build ... SYMROOT=/tmp/bpw-sym2 OBJROOT=/tmp/bpw-obj2
grep -E "warning:" /tmp/bpw-clean.log | grep -v appintents
```

干净构建的结果：**项目代码 0 警告**、0 错误。剩下唯一一行带 `warning:` 的是
Xcode 自己的 `appintentsmetadataprocessor`：「Metadata extraction skipped. No
AppIntents.framework dependency found.」——这个 App 没有 App Intents，属于工具链
噪音，不是我们的缺陷（所以历来的 grep 都带 `-v appintents`）。

验证：干净构建 + 全量 `xcodebuild test` **322 项 0 失败**、**项目警告 0**。
