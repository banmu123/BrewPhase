# Gravity Cards（Phase 2 / 2.1）— 真机人工验收清单

模拟器没有设备姿态：**以下每一项都必须在真实 iPhone 上完成**。
自动化只能证明「物理算得对、边界收得住」，证明不了「手感对不对」。

实施报告：`docs/testing/IOS_GRAVITY_CARDS_PHASE2_REPORT.md`（Phase 2）
　　　　　`docs/testing/IOS_GRAVITY_CARDS_PHASE2_1_REPORT.md`（Phase 2.1）
调试注入（仅供模拟器截图）：`xcrun simctl launch <UDID> com.brewphase.ios -BrewPhaseGravityTilt 1,0`

## 0. 前置

- [ ] 用 Xcode 装到真机（Release 或 Debug 均可），首页有内容（否则只有空态卡）。
- [ ] 「更多 → 应用 → 重力卡片」处于**开启**。
- [ ] 系统「辅助功能 → 动态效果 → 减弱动态效果」处于**关闭**（否则本阶段会自动禁用重力）。
- [ ] 准备一个**只有一张内容**的空间（例如只留一块画布 / 只留一条记录），
      用来验收 Phase 2.1 的单卡片行程。

## 0.1 Phase 2.1：单卡片行程与倾斜速度（新增，重点）

### 单卡片能滑多远

- [ ] 只有一张卡的空间里，卡片**居中**（左右空白大致相等）。
- [ ] 卡片**没有被放大**：它和别的空间里三卡堆叠中的卡一样大。
- [ ] 向左倾：卡片明显向左滑，能走到接近左侧留白处（约一个卡宽的一半）。
- [ ] 向右倾：卡片明显向右滑，能走到接近右侧留白处。
- [ ] 行程「明显」而不是十几 pt —— 视觉上应该是一整段可感知的滑动。
- [ ] 滑到两端时不会贴边、不会被裁切。
- [ ] 卡片不会滑出屏幕，也不会向上盖住本分区标题。

### 倾斜角度 → 速度

- [ ] **轻微**倾斜（几度）：卡片缓慢、轻柔地开始滑动。
- [ ] **中等**倾斜：明显加速，能感到比轻微时快得多。
- [ ] **较大**倾斜：快速滑动，速度变化清晰可感。
- [ ] **接近最大**倾斜：更快但稳定，不会失控或抖动。
- [ ] 同样倾角保持不变时，卡片速度稳定（不忽快忽慢）。
- [ ] 回正后自然减速，停在**新的位置**，不弹回原位。

### 多卡片仍守旧规矩

- [ ] 三张卡的空间里，卡片只做小幅位移（约 16pt），不互相盖住。
- [ ] 多卡片各自独立运动，前卡快、后卡慢的差异仍在。
- [ ] 让某个空间从三张变一张（删掉两张内容）再回首页：
      卡片不飞走、不跳到边界，过渡自然。

## 1. 倾斜方向（最重要）

- [ ] 手机**向右**倾（右边缘下沉）→ 卡片向右滑。
- [ ] 手机**向左**倾 → 卡片向左滑。
- [ ] 手机**底边**下沉（屏幕朝自己方向倾倒）→ 卡片向下滑。
- [ ] 手机**顶边**下沉（屏幕朝外倾斜）→ 卡片向上滑。

> 若上下与直觉相反：改 `WorkspaceMotionController.ingest` 里的 `rawY` 符号（一处），
> 再跑 `WorkspaceGravityTests` 中两条符号用例。

- [ ] 四个方向都很轻，没有「一倾就弹飞」。
- [ ] 同组三张卡动的幅度略有差异（前卡最快、后卡最慢），但不显得杂乱。

## 2. 自然惯性

- [ ] 缓慢倾斜：卡片平滑跟随，不跳帧。
- [ ] 快速左右换向：先减速再反向，没有瞬间反向跳动。
- [ ] 手机放回水平：卡片自然减速、停在新位置。
- [ ] **不会自动回到原位**。
- [ ] 放平后没有持续抖动、没有无限滑动。

## 3. 空间隔离

- [ ] Coffee / Records / Canvas 三个标题**始终不动**。
- [ ] Coffee 的卡片没有进入 Records 区域，Records 没有进入 Canvas。
- [ ] 任意倾斜下，卡片都不会盖住任何分区的标题。
- [ ] 卡片不会滑出屏幕左右边缘。
- [ ] 倾斜时页面本身不跟着滚，ScrollView 内容高度不变。

## 4. 与现有操作共存

- [ ] 点任一分区（卡片上、标题上、空白处）仍然进入**对应的列表**。
- [ ] 顶部搜索框可输入、可清除，结果行点开是正确的详情。
- [ ] **搜索键盘弹出时**卡片停止受重力影响（不再滑动）。
- [ ] 键盘收起后卡片恢复响应，且**不会突然跳一下**。
- [ ] **手指上下滚动首页时**卡片暂停受重力，滚动结束后恢复、不跳。
- [ ] 从首页推开详情再返回：卡片**回到原始堆叠**（不是上次倾斜的位置）。
- [ ] 进入某个空间再回首页：同样是原始堆叠。

## 5. 生命周期

- [ ] App 切到后台再回来：卡片停在原处（不重置），随后仍能响应倾斜。
- [ ] 回前台后没有「一进来就整组滑到底」的跳动（应已重新校准）。

## 6. 设置与无障碍

- [ ] 关闭「重力卡片」→ 首页卡片完全静止，倾斜无反应。
- [ ] 重新打开 → 恢复响应，无需重启 App。
- [ ] 打开系统「减弱动态效果」→ 重力自动失效（静态）。
- [ ] VoiceOver：首页三个分区仍各读作「进入 X，N 条内容」，卡片滑动不产生焦点跳动。
- [ ] 最大动态字体下：卡片不重叠标题、不越界。

## 7. 性能

- [ ] 连续倾斜 2–3 分钟：无明显掉帧。
- [ ] 静置 5 分钟（不倾斜）：手机不发热、耗电无异常（静止后应无逐帧计算）。
- [ ] 后台停留 5 分钟：耗电无异常（传感器应已停止）。

## 已知边界（不是 bug）

- 手机**接近竖直**握持时，上下倾斜带来的响应会明显变弱，左右依然灵敏：
  相对重力在屏幕平面上的纵向分量与「基准倾角的余弦」成正比，竖直时趋于零。
  这是物理结果，不是滤波吃掉。
- 卡片会**滑到行程边界就停住**：多卡片水平 16pt、垂直 6pt；单卡片水平约
  100pt（由真实布局算出，机型越大越多）、垂直仍是 6pt。
  垂直行程小是刻意的：再大就会盖住分区标题。
- 单卡片的行程与「内容区宽度」成正比，所以 iPad 上会比 iPhone 走得更远，
  这不是 bug。
- 空态卡（空间里没有任何内容）仍然只走保守行程：它只是占位，不该
  「没内容反而动得最远」。
