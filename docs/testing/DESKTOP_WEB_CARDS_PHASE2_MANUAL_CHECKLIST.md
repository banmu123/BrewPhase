# 网页卡片 Phase 2 — 人工验收清单

自动化覆盖了缩略图、真实导航、展开/收起、IPC 级拖出与收回、会话不重载。
下面这些**只能在真实鼠标 / 真实系统窗口**下确认，CI 不代替。

环境：macOS 或 Windows，`pnpm dev`（或安装包），中英文各过一遍。

---

## A. 真实拖出（OS 级）

1. 在 Studio Home 的「正在使用」里添加一个网页（如 `https://chatgpt.com`）。
2. 等卡片出现真实缩略图、右侧显示「已收纳」。
3. 按住卡片中部，拖到 BrewPhase 主窗口**之外**（越过窗口边缘，落在桌面上）。
4. 预期：
   - 拖动中卡片有浮起影子；光标离开窗口后出现「松手：拆成独立窗口」提示；
   - 松手后出现新的 BrewPhase 浏览器窗口，位置靠近松手点；
   - 窗口有品牌标题栏、标签条与浏览器工具栏（地址栏/后退/前进/刷新）；
   - 原网页**没有重新加载**（滚动位置、输入框内容、SPA 状态不变）；
   - 卡片仍留在架上，chip 显示「独立窗口」。
5. 用 `⌘/Ctrl + R` 刷新独立窗口的页面，确认地址与标题仍在。

## B. 原生窗口能力

在独立窗口里逐项确认：

- [ ] 拖动系统标题栏可移动窗口
- [ ] 最小化 / 最大化（或全屏）/ 关闭按钮可用
- [ ] 拖拽窗口边缘可缩放，最小尺寸不会小于 560×420
- [ ] 页面内容随窗口大小重排，不出现横向滚动条错位
- [ ] 关闭独立窗口后，标签回到主窗口（页面仍在，不重载）

## C. 拖回 / 收回

两种路径都要试：

1. **按钮**：独立窗口右上角「收回卡片架」→ 窗口关闭，卡片回到缩略状态，缩略图更新。
2. **拖动**：按住独立窗口标题区的品牌名/标题，拖到主窗口上松手 →
   标题区出现「松手：收回卡片架」提示，松手后接回。

确认：

- [ ] 不生成重复卡片
- [ ] 独立窗口不留下空壳
- [ ] 再次点击卡片，展开的是**同一个**页面（登录态、滚动位置、对话上下文都在）
- [ ] 缩略图反映收回时的画面，而不是旧截图

## D. 登录态与会话

1. 在卡片展开的面板里登录 ChatGPT。
2. 收起面板（✕ = 收起，不是关闭）。
3. 重新点击卡片 → 仍是登录态、原对话。
4. 拆出到独立窗口 → 仍是登录态；在窗口里发一条消息。
5. 收回卡片架 → 再展开 → 消息与滚动位置仍在。

Claude 额外步骤：

- [ ] 首次打开会停在 Cloudflare「正在进行安全验证」；手动勾选并登录。
- [ ] 验证通过后，卡片缩略图应更新为 Claude 应用界面（不是挑战页）。

## E. 多标签与圆桌

- [ ] 同时放 3 张以上网页卡片，缩略图各自正确，不串图
- [ ] 卡片拖到圆桌 → 圆桌出现参与者小图与名称；卡片仍在架上
- [ ] 独立窗口中的卡片仍可拖入圆桌
- [ ] 关闭卡片 → 圆桌对应座位消失，其他网页不受影响
- [ ] 圆桌停靠 ↔ 浮动切换，参与者与提问草稿不丢

## F. 状态与异常

- [ ] 新建卡片输入 `chatgpt.com`（不带协议）能规范化为 https 并打开
- [ ] 输入 `http://127.0.0.1:1` → 卡片显示「加载失败」，占位不伪造截图
- [ ] 慢页面：加载中显示 spinner + 「加载中」，完成后缩略图出现
- [ ] 最小化主窗口再恢复：缩略图不崩、卡片点击仍能展开
- [ ] 关闭全部卡片 → 回到空架引导；没有残留原生窗口

## G. 外观与语言

- [ ] 浅色 / 深色切换：卡片、名称、域名、chip 全部可读；缩略图保持网页本色
- [ ] 英文界面：卡片状态、拖出提示、收回按钮、圆桌文案均为英文，无中文残留
- [ ] 窄窗口（约 980px）：卡片架横向滚动，不折行；圆桌不溢出

## H. 多显示器 / 平台

- [ ] 第二块屏幕上拖出：窗口出现在松手的那块屏幕
- [ ] 收回后回到主屏卡片架
- [ ] Windows：标题栏按钮（最小化/最大化/关闭）与拖拽区域不冲突
- [ ] Linux：确认没有透明宿主窗口遮挡界面；未展开过的页面允许没有缩略图
