# 圆桌自由布局多网页工作空间 — 人工验收清单（Phase 4.2 Freeform）

> 规则：**未执行的项不要标通过**。真实网页的登录与操作必须人工验收；
> 自动化夹具页只证明布局机制与原生视图链路正确，不构成真实 AI 平台验收。
> 结果列填 ✅ 通过 / ❌ 失败（附现象）/ ➖ 未执行。

**产品规则提醒**：自由布局，但**面板之间不允许重叠**——以下每个拖动/缩放场景都要顺带确认没有叠上。

## 场景一：多网页同时呈现

| # | 步骤 | 结果 |
|---|---|---|
| 1 | 打开 BrewPhase，进入圆桌工作空间（「进入工作空间」） | |
| 2 | 「添加网页」输入 https://chatgpt.com/ 并添加 | |
| 3 | 添加 https://claude.ai/new | |
| 4 | 添加 https://gemini.google.com/ | |
| 5 | 确认三块真实网页同时显示（不是截图、不是空白占位） | |
| 6 | 在每块网页里点击 / 滚动 / 输入，确认网页本体可正常操作 | |
| 7 | 面板标题栏显示网站名 / 标题 / 加载状态 | |

## 场景二：自由布局（含防重叠）

| # | 步骤 | 结果 |
|---|---|---|
| 1 | 拖 ChatGPT 标题栏到左上角，位置跟手、松手即停 | |
| 2 | 拖 Claude 到 ChatGPT **正上方再压下去**：松手后两块面板**不相交**（被推到最近空位） | |
| 3 | 拖 Gemini 到下方 | |
| 4 | 拖四角缩放（↖↗↙↘），宽高同时变，网页内容跟随 | |
| 5 | 拖左右边缘改宽、上下边缘改高 | |
| 6 | 朝邻居方向缩放：自由边**停在邻居边缘**，不越过、不重叠 | |
| 7 | 把面板缩到很小：不小于最小尺寸（约 320×200） | |
| 8 | 点击不同面板：层级变化、激活面板有轻微强调 | |
| 9 | 吸附开关开/关各试一次：开启时靠边有吸附，关闭时完全自由 | |

## 场景四：原始页面状态

| # | 步骤 | 结果 |
|---|---|---|
| 1 | 在工作空间的 ChatGPT 面板里手动登录 | |
| 2 | 打开一段现有对话 | |

| 5 | 从卡片架再次展开 / 拖入圆桌：页面状态不丢 | |

## 场景五：独立窗口和归位

| # | 步骤 | 结果 |
|---|---|---|
| 1 | 工作空间里摆好几块面板，点「独立窗口」拆出 | |
| 2 | 独立窗口里拖动 / 缩放面板，正常操作网页 | |
| 3 | 点「归位」回主窗口：面板位置与拆出前**一字不差**，网页未重载 | |
| 4 | 再拆出、再归位一轮确认稳定 | |
| 5 | （可选）已拆浮窗的卡片被圆桌托管：浮窗安全关闭，页面实例不复制 | |

## 场景六：移除和关闭

| # | 步骤 | 结果 |
|---|---|---|
| 1 | 面板标题栏 ✕ 移除成员：面板消失，原网页回到卡片架（未销毁） | |
| 2 | 在卡片架上直接关闭一张圆桌成员卡片：圆桌面板自动消失，其他成员不受影响 | |
| 3 | 移除后重新加入：拿到新的默认空位（不复活旧位置） | |

## 场景七：持久化与幽灵面板

| # | 步骤 | 结果 |
|---|---|---|
| 1 | 摆好多块面板（移动 / 缩放 / 置顶），正常退出应用 | |
| 2 | 重新启动，进入工作空间：布局恢复 | |
| 3 | 恢复出的面板显示「标签已关闭」（幽灵态）与「重新打开」按钮 | |
| 4 | 点重新打开：网页按**原几何**复活（位置/尺寸/层级不变），登录态需重新登录（新会话属正常） | |
| 5 | 拆出窗口后重启应用、再归位：布局一致 | |

## 已知问题（验收时不必报障）

- 无 GPU 环境下 `browser.e2e` 真指针拖拽用例不稳定（自动化环境问题，与产品无关）。
- 工作区被面板完全挤满时新增成员的落位兜底（极难触发）。
- 幽灵面板重开后需要重新登录（WebContents 是新会话，属预期）。
