# 已知限制

这份清单只写"现在确实做不到 / 做错了"的事，不写愿望清单。

## 1. 无法验证的部分（BLOCKED）

| 项 | 原因 |
|---|---|
| UI 真实截图验收 | 本机 Android SDK 没有 `system-images`，无法创建 AVD；下载镜像与启动模拟器在当前网络/时间条件下不可行。**没有用静态图或设计稿冒充运行截图。** |
| Instrumented 测试、Room 迁移测试 | 同上：无设备、无模拟器。`androidTest` 依赖已声明但未执行。 |
| 备份跨端兼容 | 备份功能本身未实现；也没有 iOS 真机生成的 `.brewphasebackup` 样本可验证。 |
| Desktop 同步联调 | 同步客户端未实现（见 §2）。 |

## 2. 未实现的功能

- **Desktop 同步**：扫码配对、Keystore token、HMAC 签名、实体同步、媒体分块与断点续传、
  冲突/删除指纹、自动推送、解除配对——全部 `NOT_STARTED`。界面上没有假入口。
- **备份与恢复** `.brewphasebackup`（v2–v4）、**JSON/CSV 导出**。
- **RAG 问答**：`knowledge_base.json`、`HybridRetriever`、`EntityGraph`、`ExtractiveLLMProvider`
  未移植；Ask 目前只是关键词检索 + 结构化事实。
- **风味窗口预测**：Core ML 模型未转换，也不显示任何预测曲线或峰值日。
- **视频播放 / 内嵌播放器**：只提供"打开原链接"。
- **链接元数据抓取**（OG、GitHub stars、B 站信息）：字段已预留，抓取器未写。
- **示例数据载入**：只有"删除示例数据"，没有 7 包样例的载入。
- **手写品鉴编辑器**：仓库层有 `saveTasting`，界面只有展示与删除。
- **冲煮诊断**（酸/苦判断、调整建议）：未移植。
- **深色模式**：只做浅色。深色需要重校咖啡色相，没校就不假装支持。

## 3. 实现但不完整

- **豆子图片**：数据层有 `imagePath`，列表/详情能显示；**编辑器没有选图入口**。
- **编辑已有冲煮**：路由支持 `brewId`，但详情页没有"编辑这条"按钮。
- **Tab 切换**：数据会重新加载，列表滚动位置会丢（未使用 `SaveableStateHolder`）。
- **提醒**：规划器与调度器写好了，但**保存豆子/规则后没有调用重排**；
  设置页也没有申请通知权限的按钮（只检查权限状态）。
- **语言切换**：偏好存了，但没有调用 per-app locale API，切换后不会立即生效；
  英文界面里 Insights 的证据文案、Ask 的回答、部分标签仍是硬编码中文。
- **品鉴时间线**：只有列表，没有 iOS 那种图形化时间线。
- **Insights 参数偏差 / 下一步**：规则很薄，样本 ≥ 3 才给，且文案未本地化。

## 4. 工程性缺口

- **没有 Gradle wrapper jar**：当前环境不允许把二进制写进版本库。用本机 Gradle 8.14，
  或执行一次 `gradle wrapper --gradle-version 8.14` 生成。
- **Lint 未跑**：时间不足，未执行 `lintDebug`。
- **数据库恢复入口**：数据库损坏时没有恢复/诊断 UI（虽然也没有 destructive migration，
  不会静默清库）。
- **`androidTest` 为空**：只有依赖声明，没有用例。

## 5. 与 iOS 的语义差异（已知且刻意）

- 通知标识符不同：Android 用 `("brewphase.bean.$beanId.$kind").hashCode()` 生成本机 ID，
  跨端只同步"意图"。
- 时间精度：数据库存 epoch millis，domain 用 `LocalDate`；iOS 用 `Date`。按天比较的
  逻辑两端一致（都以当地日历日的 00:00 为界）。
- 图片/视频存**文件名**而不是绝对路径，两端相同；绝对路径在换设备后会失效。
